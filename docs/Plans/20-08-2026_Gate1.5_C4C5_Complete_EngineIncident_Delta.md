### 5.1 `PopulateTreeColumn` — nâng từ mô tả 1 dòng lên node flow đầy đủ

```
PopulateTreeColumn() — Function [AS-BUILT K2 20/08/2026]
Đọc thẳng class var FolderTree (đã SET bởi caller: Event Construct Then_1 hoặc
SwitchInventoryMode). KHÔNG nhận param.

ClearChildren(VerticalBox_44)
▶→ Sequence
  then_0 → Create WBP_TreeNode "AllNode" (FolderPath="", FolderName="All", IndentLevel=0)
           → Bind OnNodeSelected → (handler tree furniture/material)
           → AddChild(VerticalBox_44)
           → RefreshDisplay(bIsActive = ...)      [node mang cờ ErrorType=1 — ghi chú nhẹ
                                                    của editor, KHÔNG phải lỗi runtime;
                                                    xác nhận vô hại phiên 20/08]
  then_1 → Map_Find(FolderTree, Key="") → Lvl1CSV, bFound
           Branch(bFound)
             False → [dead-end hợp lệ]
             True  → ParseIntoArray(Lvl1CSV, ",") → Lvl1Names
```

### 5.2 `Event Construct` (WBP_FurnitureInventory) — xác nhận Then 0-5 khớp export

Doc hiện tại ghi Then 0-4 (bản v2.4). Export 20/08 xác nhận cấu trúc thật là **6 nhánh
Sequence (Then 0-5)**. Cập nhật mô tả (giữ nội dung, chỉ bổ sung/đánh dấu as-built):

```
Event Construct — [AS-BUILT K2 verified 20/08/2026]
Entry → SetTimer(0.5s → InitMinimizedHeight)   ← latent, KHÔNG chặn exec, chạy song song
      → SET SizeBox Height → SET CurrentCategory = "All"
      → ForEachLoop(CategoryList)              ← ⚠️ CategoryList hiện RỖNG (chưa từng SET ở
                                                  đâu) → Loop Body chạy 0 lần. Xem ghi chú.
        Completed → Sequence:
          then_0: Bind BTN_AllCategory.OnCategorySelected
          then_1: BuildFolderTree → SET FurnitureFolderTree → PopulateTreeColumn
                  → FilterByFolderPath → UpdateTabHighlight
          then_2: GetAllActors(BP_UndoManager)[0] → SET UndoManagerRef
                  → Bind OnRestoreCompleted → OnSceneRestored
          then_3: GetAllActors(BP_FurnitureInputManager)[0]
                  → Bind OnSelectionChanged → OnSelectionChangedMaterial
          then_4: UpdateResizeHandles → UpdateSpecialHighlight
          then_5: GetAllActors(BP_ComboManager)[0] → IfThenElse(Length > 0)
                    True  → SET ComboManagerRef → Bind OnComboLibraryChanged → LoadComboLibrary
                    False → [dead-end]   ← ⚠️ race condition tiềm ẩn, xem ghi chú
```

> **Ghi chú 1 (CategoryList rỗng — 20/08):** biến `CategoryList` chưa từng được SET ở bất kỳ
> đâu → ForEachLoop chạy 0 lần. Loop rỗng KHÔNG chặn `Completed` → Sequence vẫn chạy bình
> thường qua cả 6 nhánh. Đây KHÔNG phải nguyên nhân sự cố 20/08 (gốc là engine binary). Ghi
> lại như observation — nếu sau này cần dựng nút category động thì đây là chỗ thiếu nguồn nạp.
> Chưa quyết fix, chưa phải bug đang mở.
>
> **Ghi chú 2 (then_5 race condition tiềm ẩn):** nhánh False của `IfThenElse(GetAllActorsOfClass
> (BP_ComboManager) Length > 0)` là dead-end. Nếu Construct chạy lúc BP_ComboManager chưa kịp
> spawn → ComboManagerRef không set → LoadComboLibrary không chạy → combo rỗng im lặng. Phiên
> 20/08 xác nhận 8/8 actor spawn đủ SAU Play nên chưa gặp, nhưng đây là điểm mong manh về thứ
> tự spawn. Ghi vào Open_Bugs như rủi ro tiềm ẩn (KHÔNG phải bug đang xảy ra).
