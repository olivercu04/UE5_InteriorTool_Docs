## 3. Canonical state + conversion rules (khóa cứng)

```cpp
struct FInteriorHSVState
{
    float H; // [0, 360)
    float S; // [0, 1]
    float V; // [0, 1]
    float A; // [0, 1] — giữ trong state, UI v1 KHÔNG expose alpha slider
};
```

**RGB = derived, không phải state gốc.** HSV → LinearRGB chỉ tính lúc expose ra public API.

**SetColor(FLinearColor) — RGB → HSV, rule bảo toàn Hue (CHỈ dựa S, KHÔNG dựa V):**
```
if bIsInteracting:  return   // no-op khi user đang kéo — interaction thắng programmatic

(H_new, S_new, V_new) = RGB→HSV(NewColor)

S = S_new
V = V_new
A = NewColor.A
if S_new > AchromaticSaturationThreshold:   H = H_new    // màu có sắc → cập nhật Hue
else:                                        (giữ H cũ)   // achromatic (đen/xám/trắng) → Hue sống

sync Slate controls
// KHÔNG broadcast Begin/Changed/End
```

- **Điều kiện Hue CHỈ là `S_new > threshold`.** KHÔNG thêm `&& V > ...` — vì đen thẫm-có-sắc
  (S=1, V=0.05) vẫn là màu rõ, phải giữ Hue. Chỉ S=0 (achromatic) mới làm Hue vô nghĩa.
- **`AchromaticSaturationThreshold`** = hằng số của riêng picker, định nghĩa 1 CHỖ (đề nghị `1e-4`),
  KHÔNG hardcode rải rác ở cả convert-in lẫn convert-out.
- **`H` tự đóng vai `LastChromaticHue`** — không cần biến riêng (mỗi lần S>threshold thì H cập nhật
  và "nhớ"; achromatic thì H đứng yên = giá trị chromatic cuối).

> **Quyết định (14/09, as-built):** SetColor với màu achromatic (pure black/gray) KHÔNG giữ S —
> ghi S=0 trung thực theo RGB→HSV. Chỉ H được bảo toàn (S=0 → H vô hại với output). KHÔNG mở rộng
> thành "giữ S khi V thấp" — nhớ ngầm kiểu đó là nguồn bug. Phục hồi màu-trước-khi-đen là việc của
> **Undo (G6)**, KHÔNG phải picker tự nhớ ngầm. Hệ quả trực tiếp: case #9 mục 6 sửa lại (xem đó).

**Value gradient EndColor cập nhật động:**
```
Value gradient: Start = Black, End = HSV(State.H, State.S, V=1) → LinearRGB
→ mỗi khi H hoặc S đổi ở wheel, gradient EndColor phải recompute
```

**SSlider chỉ chạm State.V** — không round-trip qua RGB → Hue sống nguyên khi V=0.

## 4. Public Blueprint API (BẤT BIẾN — nhốt mọi khác biệt engine 5.5→5.8 sau lớp này)

```
SetColor(FLinearColor NewColor)   // silent, theo rule mục 3
GetColor() → FLinearColor         // HSV→LinearRGB

Event OnInteractionBegin
Event OnColorChanged(FLinearColor)
Event OnInteractionEnd(FLinearColor)
```

G7.1+ (panel/row) CHỈ được chạm lớp này. `SColorWheel`/`SSimpleGradient`/`SSlider` đổi signature
khi nâng engine → sửa TRONG plugin (adapter), Blueprint G7 không biết, không re-wire.

**Lifecycle mapping bên trong picker:**
```
Wheel mouse down  → bIsInteracting=true → OnInteractionBegin
Wheel drag        → sửa H,S → recompute gradient End → OnColorChanged
Wheel mouse up    → bIsInteracting=false → OnInteractionEnd
Slider mouse down → bIsInteracting=true → OnInteractionBegin
Slider drag       → sửa V → OnColorChanged
Slider mouse up   → bIsInteracting=false → OnInteractionEnd
```

**UWidget wrapper:** override `ReleaseSlateResources()` sạch (dự án bắt clear ref chống VRAM leak
— R4). SNew trong `RebuildWidget()`, KHÔNG trong constructor (precedent: đây là gốc lỗi packaged
của các wrapper khác).
