### 3.3 `BuildFolderTree` — nâng cấp `CollectFolderTargets` — ✅ DONE (08/07, Task Card #1)
> ⚠️ **[RENAME khác plan gốc]** Wrapper thực thi tên là **`BuildComboFolderTreeNodes(ExcludePath)`**, KHÔNG phải `BuildFolderTree` như pseudocode dưới — trùng tên với hàm cũ phía Material/Furniture catalog. Recursive core thực thi tên là `BuildFolderTreeRecursive` (khớp pseudocode) + hàm phụ mới `GetFilteredChildren` (Pure, tách bước filter). Node flow THẬT (export K2Node, xác nhận 08/07) đã ghi đầy đủ ở `WBP_FurnitureInventory.md` v3.10 — 2 khác biệt nhỏ so với pseudocode dưới: `GetFilteredChildren` gọi 1 lần/child (dùng chung cho `ChildCount`+`HasChildren`), node "(Gốc)" có `bIsLast=False`.
```
BuildFolderTreeRecursive(ParentPath, ExcludePath, AncestorsContinue : Array<Bool>) → Array<S_FolderTreeNode>  — Function thuần
Local: LocalResult (Array<S_FolderTreeNode>), ChildAncestors (Array<Bool>)

Map Find(ComboFolderTree, ParentPath) → CSV, bFound
Branch(bFound == false) → Return LocalResult (rỗng)
Parse Into Array(CSV, ",") → RawChildren
FilteredChildren = RawChildren bỏ child mà FullPath == ExcludePath OR StartsWith(ExcludePath+"/")
Length(FilteredChildren) → Count
ForEach FilteredChildren (child, index i):
  FullPath = ParentPath=="" ? child : ParentPath+"/"+child
  isLast   = (i == Count-1)
  Make S_FolderTreeNode(Path=FullPath, DisplayLabel=child, Depth=Length(AncestorsContinue),
       HasChildren=(con sau-exclusion của FullPath).Num>0, ChildCount=(số con sau-exclusion),
       ContinuesAncestors=AncestorsContinue, bIsLast=isLast)
  ADD LocalResult(node)
  SET ChildAncestors = COPY(AncestorsContinue)     ← COPY LOCAL, không mutate mảng cha
  Add(ChildAncestors, NOT isLast)                  ← tổ tiên "còn em" ⇔ mình KHÔNG phải con út
  BuildFolderTreeRecursive(FullPath, ExcludePath, ChildAncestors) → Sub
  Array_Append(Target=LocalResult, Source=Sub)     ← ⚠️ D-C5.4-1: Target là accumulator, KHÔNG đảo chiều
ForEach Completed → Return LocalResult
```
Wrapper `BuildFolderTree(ExcludePath)`: thêm entry `"(Gốc)"` (Path="") + `BuildFolderTreeRecursive("", ExcludePath, [])`.
> **Move:** ExcludePath = MovingPath (giữ hành vi C5.4). **Save:** ExcludePath = "" → không loại gì.
