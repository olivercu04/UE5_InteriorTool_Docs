## KHỐI A — Luồng xuyên 3 lớp (end-to-end, chạy liên tục 1 phiên PIE)

Chạy tuần tự, ghi bảng PASS/FAIL từng bước. Data thật (≥8 combo, nested ≥3 tầng, có folder tiếng Việt + folder rỗng).

```
A1  Mở Move dialog (right-click combo) → picker hiện full cây, guide line │├└ đúng,
    folder chứa combo đang move BỊ LOẠI (ExcludePath=MovingPath), tag "hiện tại" hiện đúng folder cha.
A2  Trong Move: expand/collapse vài nhánh + search "sofa" → lọc đúng + highlight →
    xóa query → về đúng state expand trước search (6A). Chọn 1 folder → Confirm →
    combo chuyển đúng folder (verify ở cây inventory sau khi đóng).
A3  Mở Save dialog (save combo mới) → picker hiện full cây, KHÔNG loại folder nào (ExcludePath=""),
    KHÔNG có tag "hiện tại" (bShowCurrentTag=OFF), nút "+" hiện (bAllowInlineCreate=ON).
A4  Trong Save: bấm "+" → tạo "New Folder (N)" → tự vào rename mode, text bôi đen →
    gõ tên tiếng Việt "Phòng Khách" → commit → node đổi tên + auto-select → save combo vào đó.
    Verify: combo mới nằm đúng "Phòng Khách" ở cây inventory.
A5  ISOLATION (mấu chốt #2): ngay sau A4, mở lại Move dialog →
    state KHÔNG dính từ Save (không còn "Phòng Khách" đang selected, expand state của Save
    không lây sang Move). Mỗi vỏ mở ra ở state sạch của chính nó.
A6  Save combo vào "(Gốc)" (dòng ghim đầu) → combo không thuộc folder nào → verify inventory.
A7  Move 1 folder CHA có con → search + chọn đích → con di chuyển theo (không mồ côi).
```
