### Bước 2 — `PathMatchesQuery` + `BuildSearchOverride` (Function trên PICKER — §4b/§4c)

### Bước 3 — Ghép nhánh search vào `RefreshVisibleRows` (§4d)

### Bước 4 — Wire `SB_SearchFolder.OnSearchTextChanged` (§PHẦN 5)
⚠️ ĐÂY LÀ ĐIỂM DỄ SÓT NHẤT — thân event phải quản lý ĐỦ CẢ 2 CHIỀU vào/ra search:
```
▶ SET QueryStr = Text → ToString
▶ Branch( Len(Trim(QueryStr)) == 0 )
   True  → SET bIsSearching = False           ← CHIỀU RA (thoát search)
           Array Clear(SearchExpandOverride)   ← reset biến tạm, tránh dính rác lần sau
   False → SET bIsSearching = True             ← CHIỀU VÀO
           BuildSearchOverride(QueryStr)
   [merge]
▶ RefreshVisibleRows()
```
- Widget = `SB_SearchFolder` (Search Bar), event = `OnSearchTextChanged` (KHÔNG phải `ETB_Search.OnTextChanged` — deviation [SWAP] đã log).
- `Trim` để "   " (toàn khoảng trắng) không kích search.
- **Chiều RA (nhánh True) chính là cơ chế test mục 8 (6A must-have):** xóa query → `bIsSearching=False` → `RefreshVisibleRows` tự dùng lại `ExpandedFolders` cũ (chưa từng bị đụng khi search) → về đúng state trước search MIỄN PHÍ. KHÔNG được bỏ nhánh này.
- ⚠️ `QueryStr` = biến tạm trong Custom Event: nếu editor chặn local var trong Custom Event → dùng class var tạm HOẶC nối thẳng `Text→ToString` vào các node cần (không SET). Confirm khi build.
