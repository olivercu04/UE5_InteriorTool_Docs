## 1. `docs/Widgets/WBP_FolderPickerRow.md` — bump **v1.0 → v1.1**

### Sửa `SetNode(Node : S_FolderTreeNode)`
Dòng đầu hàm — THÊM (trước đây thiếu hoàn toàn):
```
▶ SET RowNode = Node          ← MỚI, ngay sau Entry
```

### Sửa phần cuối `SetNode` (nhánh Branch HasChildren)
Trước đây chỉ có:
```
Branch(Node.HasChildren)
   True  → Set Visibility(TXT_Arrow, Visible)
   False → Set Visibility(TXT_Arrow, Hidden)
```
Nay — THÊM `SetVisibility(BTN_Arrow, ...)` song song ở cả 2 nhánh:
```
Branch(Node.HasChildren)
   True  → Set Visibility(TXT_Arrow, Visible)
            Set Visibility(BTN_Arrow, Visible)     ← MỚI
   False → Set Visibility(TXT_Arrow, Hidden)
            Set Visibility(BTN_Arrow, Hidden)       ← MỚI (Hidden, không Collapsed — giữ layout)
```

### Đính chính "Button handlers" (2b Part A)
Xóa đoạn ghi sai trong bản v1.0:
```
BTN_Arrow.OnClicked → HandleArrowClicked (Custom Event)
   ▶ Broadcast OnRowExpandClicked(RowNode.Path)
BTN_Name.OnClicked  → HandleNameClicked (Custom Event)
   ▶ Broadcast OnRowSelected(RowNode.Path)
```
Thay bằng as-built THẬT (xác nhận qua export K2Node 11/07):
```
On Clicked (BTN_Arrow) ▶→ Call On Row Expand Clicked(Target=self, Path=Break(RowNode).Path)
On Clicked (BTN_Name)  ▶→ Call On Row Selected(Target=self, Path=Break(RowNode).Path)
```
Không có Custom Event trung gian nào ở cả 2. `Path` lấy qua `Break S_FolderTreeNode(RowNode)` — không phải hardcode, không phải qua param `Node`.

### "Còn nợ" — không đổi
`SetSearchHighlight(bMatch)` (Part 2c) · `EnterRenameMode`/host `WBP_EditableLabel` (2d) — vẫn chưa build.
