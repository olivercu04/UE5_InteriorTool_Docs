## L-rules áp dụng
- **L9:** state (`ExpandedFolders`, `SelectedPath`, `bIsSearching`, `SearchExpandOverride`) = Class Variable. Handler bound (`OnRowExpandClicked`/`OnRowSelected` từ row, `OnTextChanged` từ SearchBox) = **Custom Event** (Bind bắt buộc).
- **L2:** `IsPathVisible`/`PathMatchesQuery`/`BuildSearchOverride`/`RefreshVisibleRows` là **Function** → mọi Branch về Return; trong LoopBody dead-end hợp lệ (KHÔNG phải Event chain).
- **L11 n/a:** toàn String, không async → không aliasing.
- **Array pass-by-ref:** các function chỉ ĐỌC `Folders`/`ExpandedFolders`, không mutate trong loop → không cần copy. Handler expand toggle mutate `ExpandedFolders` = SET class var trực tiếp (KHÔNG trong loop) → an toàn.

## Node cho phép
`Parse Into Array` ("/") · `Append String`/`Concat_StrStr` · `Array Contains` · `Add Unique` (Array) · `Remove Item` (Array) · `Array Clear` · `Array Length` · `Array Get` · `Is Valid Index` · `ForEachLoop` · `ForEachLoopWithBreak` · `Branch` · `Select String` · `Equal (String)` · `NOT Boolean` · `BooleanAND`/`BooleanOR` · `Contains (String)` · `To Lower` · `Trim` · `Clear Children` · `Create Widget` · `Add Child` (ScrollBox) · `SetText`/`SetVisibility` · gọi `SetNode`/`SetExpanded`/`SetSearchHighlight` của row · `Get Text` (đọc SearchBox) · Bind dispatcher.

> ⚠️ **PHÂN BIỆT 2 node "Contains" — dễ nhầm chết người (bài học cũ Array vs String Contains):**
> - **`Array Contains`** (kéo từ biến Array) = so khớp CHÍNH XÁC element → dùng cho `ExpandedFolders` (path đầy đủ).
> - **`Contains` (String, KismetStringLibrary)** = tìm substring → dùng cho search match tên folder.
> Dùng nhầm = search sai (false positive) hoặc expand-check sai.

## PHẦN 4 — WBP_FolderTreePicker: Functions

### 4a. `IsPathVisible(Path : String) → Boolean` — Function
Node hiện ⇔ MỌI tổ tiên trực tiếp ∈ ExpandedFolders. Top-level (không có "/") luôn true.
**Local var:** Segments (Array\<String\>), CurrentPrefix (String), n (Int), bHidden (Bool)
```
▶ SET Segments = Parse Into Array(Path, "/")
▶ SET n = Array Length(Segments)
▶ SET bHidden = False
▶ Branch(n <= 1) → True → Return(True)          ← "(Gốc)" (Path="") hoặc top-level → luôn hiện
   False ↓
▶ SET CurrentPrefix = Array Get(Segments, 0)      ← prefix = segment đầu (tổ tiên gốc)
▶ ForEachLoopWithBreak(Segments):
     LoopBody (Array Element, Array Index):
       ▶ Branch( Array Index >= (n-1) )            ← tới CHÍNH-NÓ (index cuối) → DỪNG kiểm
          True  ▶→ Break
          False ▶→ Branch( NOT Array_Contains(ExpandedFolders, CurrentPrefix) )
                     True  ▶→ SET bHidden=True → Break     ← 1 tổ tiên chưa expand → ẩn
                     False ▶→ SET CurrentPrefix = Concat(CurrentPrefix, Concat("/", Array Get(Segments, Array Index + 1)))
     Completed ▶→ Return( NOT bHidden )
```
> Q8: Container=Function (có Return) | IsValid: index bounded bởi loop → an toàn | L2: mọi Branch → Return/Break, Completed→Return ✓ | No latent ✓ | 6A: n/a — pure reader
>
> **Truy vết tay `A/B/C` (n=3) — xác nhận không off-by-one:**
> | Array Index | `Index >= 2`? | check | CurrentPrefix sau vòng |
> |---|---|---|---|
> | 0 | No | "A" mở chưa | nối → "A/B" |
> | 1 | No | "A/B" mở chưa | nối → "A/B/C" |
> | 2 | **Yes → Break** | — | — |
> → kiểm đúng 2 tổ tiên "A","A/B", KHÔNG kiểm chính nó "A/B/C". ✓
>
> **Ví dụ đời thường:** path `A/B/C` = "Nhà A → Phòng B → Ngăn C". Muốn thấy "Ngăn C" phải mở "Nhà A" VÀ "Phòng B" (2 tổ tiên), không cần mở chính "Ngăn C". Gặp tổ tiên nào chưa mở → ẩn ngay.

### 4b. `PathMatchesQuery(Path : String, Query : String) → Boolean` — Function
Tên folder (segment cuối) chứa Query (không phân biệt hoa thường).
**Local var:** Segments (Array\<String\>), LastSeg (String)
```
▶ SET Segments = Parse Into Array(Path, "/")
▶ Branch( Array Length(Segments) == 0 )
   True  ▶→ Return(False)          ← "(Gốc)" không tham gia search
   False ▶→ SET LastSeg = Array Get(Segments, Array Length -1)
          ▶ Return( Contains( To Lower(LastSeg), To Lower(Query) ) )   ← String Contains (substring)
```
> Q8: Container=Function | L2: 2 nhánh Return ✓ | No latent ✓ | 6A: n/a
> ⚠️ `Contains` = **String Contains** (substring), KHÔNG Array Contains.

### 4c. `BuildSearchOverride(Query : String)` — Function
Với mỗi node khớp query, thêm TẤT CẢ tổ tiên vào `SearchExpandOverride`.
**Local var:** Segments (Array\<String\>), Prefix (String)
```
▶ Array Clear(SearchExpandOverride)
▶ ForEachLoop(Self.Folders) — node:
     ▶ Branch( PathMatchesQuery(node.Path, Query) )
        True  → SET Segments = Parse Into Array(node.Path, "/")
                 SET Prefix = ""
                 ForEachLoop(Segments) — (seg, idx):
                    ▶ Branch(idx == 0)
                       True  → SET Prefix = seg
                       False → SET Prefix = Concat(Prefix, Concat("/", seg))
                    ▶ Branch( idx < (Array Length(Segments) -1) )    ← chỉ thêm TỔ TIÊN (không thêm chính node khớp)
                       True  → Add Unique(SearchExpandOverride, Prefix)
                       False → [dead-end]
        False → [dead-end]
   Completed → (hết hàm)
```
> Q8: Container=Function | IsValid: n/a | L2: LoopBody dead-end hợp lệ (nested loop, không Event chain), Completed=cuối hàm ✓ | No latent ✓ | 6A: n/a — chỉ ghi biến tạm, reset đầu bằng Clear

### 4d. `RefreshVisibleRows()` — Function (SINGLE SOURCE — lo cả expand-mode + search-mode)
**Local var:** bShow (Bool), Row (WBP_FolderPickerRow ref), QueryStr (String)
```
▶ SET QueryStr = Get Text(ETB_Search) → ToString     ← đọc 1 lần đầu hàm
▶ Clear Children(SB_Rows)
▶ ForEachLoop(Self.Folders) — node:
     ── quyết định row này CÓ HIỆN không ──
     ▶ Branch(Self.bIsSearching)
        True  → SET bShow = ( Array_Contains(SearchExpandOverride, node.Path)
                              OR PathMatchesQuery(node.Path, QueryStr) )   ← tổ tiên-đường-search HOẶC chính nó khớp
        False → SET bShow = IsPathVisible(node.Path)
     [merge] ▶ Branch(bShow)
        True  →
           ▶ Create Widget(WBP_FolderPickerRow) ●→ Row
           ▶ Row.SetNode(node)
           ── expand-state của arrow ──
           ▶ Branch(Self.bIsSearching)
              True  → Row.SetExpanded(True)                                 ← search-mode: arrow ▼, badge ẩn
                       Row.SetSearchHighlight( PathMatchesQuery(node.Path, QueryStr) )
              False → Row.SetExpanded( Array_Contains(ExpandedFolders, node.Path) )
                       Row.SetSearchHighlight(False)
           ▶ Bind Row.OnRowExpandClicked → HandleRowExpandClicked
           ▶ Bind Row.OnRowSelected → HandleRowSelected
           ▶ Add Child(SB_Rows, Row)
        False → [dead-end]
   Completed → (hết hàm)
```
> Q8: Container=Function | IsValid: Row valid cùng frame (Create Widget đồng bộ) | L2: mọi Branch có hành động/dead-end hợp lệ, Completed=cuối hàm ✓ | No latent ✓ | 6A: n/a — render thuần, không mutate state
> **Vì sao search-mode SetExpanded(True):** search chỉ hiện node liên quan (đường tới match + match). Cho tất cả arrow=▼, badge ẩn để nhìn như "đã bung sẵn". Hiển thị tạm — thoát search về lại expand-state cũ vì ExpandedFolders KHÔNG bị đụng.

### 4e. `SetFolders(Nodes : Array<S_FolderTreeNode>)` — SỬA (đã có từ 2a, đổi thân)
```
▶ SET Folders = Nodes
▶ RefreshVisibleRows()
```
